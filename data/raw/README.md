# data/raw — place for REAL measured S-parameter files

This directory is intentionally empty: **no measured data are included in this repository**.
All results shipped under `results/` are computed from clearly labelled *synthetic* data
(`data/synthetic/`, generated by `examples/make_synthetic_s2p.py`).

## Accepted input formats

### Touchstone v1 `.s2p` (preferred)

* Option line `# <unit> S <fmt> R <z0>` with unit ∈ {Hz, kHz, MHz, GHz}, fmt ∈ {RI, MA, DB}.
* Data lines: `f  S11  S21  S12  S22` (Touchstone 2-port order: **S21 before S12**).
* `R` must equal the characteristic impedance of the empty sample holder (normally 50 Ω for
  a 7 mm airline); S-parameters must be normalised to the empty holder.
* Touchstone 2.0 keyword files: use `--touchstone-backend skrf` (requires scikit-rf).

### CSV

Header `f_hz,s11_re,s11_im,s21_re,s21_im[,s12_re,s12_im,s22_re,s22_im]`.
If S12/S22 are absent they are taken equal to S21/S11 (reciprocal, symmetric sample).

## Calibration / reference-plane requirements

* Two-port calibration (TRL or SOLT) with the reference planes at known positions.
* Either (a) the planes coincide with the sample faces, (b) supply the distances from each
  plane to the sample face (`--offset1-mm`, `--offset2-mm`), or (c) for non-magnetic samples
  supply the holder length (`--holder-length-mm`) to use the reference-plane-invariant NIST
  formulation (only L_air − L is then needed).
* Record for every file: sample length (and its uncertainty), holder length, calibration
  kit/method, temperature, and whether the sample is known to be non-magnetic.

## Processing

```bash
python -m nrw.cli --input data/raw/<file>.s2p --thickness-mm <L> --method iterative-eps-mu \
    --uncertainty --output results/<name>
```

See README.md (section "Processing a measurement") for all options.
