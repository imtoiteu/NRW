# Terminology verdicts

Rating scale:

* **correct** – defensible as written.
* **conditionally correct** – true only under conditions the sentence must state.
* **too strong** – the direction is right, but it claims more than the evidence supports.
* **incorrect** – contradicted by primary sources or by the physics.

Citations `[Rn]` refer to `docs/references.md`; section numbers refer to `docs/theory_review.md`
(TR).

| 1 | "The NIST-modified NRW method eliminates half-wave divergence." | **Incorrect** for simultaneous ε, μ; **conditionally correct** only for the permittivity-only (μ_r = 1) NIST method | "NIST-modified NRW" is not a defined NIST term (TR §5 (1)). The closest NIST section title, "Modified Nicolson-Ross: Reference-Plane Invariant Algorithm" ([R7] §7.5.2), solves for ε and μ, and NIST states that such solutions "will be unstable at integral multiples of one-half wavelength in the material" for low-loss magnetic and dielectric samples ([R7] §7.3.1; [R4] §2.2; [R6] Table 5.1). Kim & Baker-Jarvis (NIST, 2014) show that the iterative BJ equations give the same λ/2 artifacts as NRW when ε and μ are both unknown, and remove them only with μ_r = 1 and transmission only ([R11] §2.1). The λ/2 elimination claimed by Baker-Jarvis et al. 1990 is for permittivity ([R3] abstract; [R4] Ch. 1: "by setting the permeability to unity"). The underlying cause is loss of identifiability of the ε/μ split, which no reformulation of the same single-sample data can remove (TR §3.2). | "For non-magnetic samples (μ_r = 1 assumed), we used the NIST iterative transmission/reflection permittivity algorithm [Baker-Jarvis et al. 1990; NIST TN 1341], which avoids the half-wavelength instability of the NRW equations. When ε_r and μ_r are retrieved simultaneously from a single sample, the problem is intrinsically ill-conditioned near L = nλ_g/2 [NIST TN 1355-R §2.2; TN 1536 §7.3.1]. Frequencies within ±Δf of these points are flagged (or bridged by a two-length measurement / causal-model fit)." |
| 2 | "Continuous phase unwrapping guarantees the correct physical phase branch." | **Incorrect** (as a guarantee); the procedure is **conditionally correct** | Unwrapping only propagates the initial branch. It is right only if all of these hold (TR §5 (7)–(8)): (i) the branch at f_min is known, e.g. sample shorter than λ_g/2 at f_min, or anchored by group delay or a second length; (ii) Δf·τ_g < ½ for the quantity unwrapped; (iii) phase noise is ≪ π (|S21| well above the noise floor); (iv) no data gaps or separate waveguide bands; (v) no genuine branch changes. [R17] §5 doubts that continuity-based branch selection "can be automated for general structures" because "branch crossings and other special features may obscure the choice". Weir's group-delay method assumes weak dispersion ([R11]: "If the material sample possesses a dispersive characteristic, the correct branch cut will remain ambiguous"). | "The phase of T was unwrapped from the lowest measured frequency, where the sample is electrically shorter than half a guided wavelength (βL < π), so the branch index m = 0 there is unambiguous. The frequency step satisfies Δf·τ_g < 0.5 throughout. The resulting branch was cross-checked by [group-delay/phase-delay agreement, a second sample length, forward-model residuals]." Alternatively, report the branch index m(f) and the checks it passed. |
| 3 | "The retrieved parameters strictly satisfy the Kramers–Kronig relations." | **Incorrect / unverifiable** for 2–18 GHz data | The KK integrals extend over 0 < ω < ∞, and "direct solution requires complete data over full spectrum" ([R4] App. F; [R6] App. D). Band-limited data can only be shown *consistent* with causality up to unknown out-of-band contributions ([R24]; subtractive KK [R26], once-subtracted form in [R4] eqs. (6.183)–(6.184)). KK-based branch selection has unquantified truncation error ([R17] §5.2.3). Exact KK compliance holds only for a *model* that is causal by construction (e.g. Debye/Lorentz pole sums; NIST's causal pole/Laurent regression, [R6] Ch. 3, [R8]). The KK relation printed in [R4] (6.181) and [R6] (D.8) also carries a sign that fails a Debye check under ε'' ≥ 0 (TR §7). Implement from TR §7, not from the printed NIST equation. | "Over 2–18 GHz the retrieved spectra are consistent with causality within the stated uncertainty. A singly-subtractive Kramers–Kronig test anchored at f₀ reproduces ε'(f) to within X, and the data are well described by a causal [Debye/Lorentz] dispersion model (which satisfies the Kramers–Kronig relations by construction) with RMS residual Y." |
| 4 | "The complex permittivity and permeability were retrieved … using the Nicolson–Ross–Weir method … NIST/Baker–Jarvis-type robust formulation." | **Conditionally correct but ambiguous; too strong as "robust" for (ε, μ)** | "NRW" and "Baker-Jarvis/NIST" are different algorithms. The Baker-Jarvis ε-only method assumes μ_r = 1 ([R4], [R34], [R35]) and so cannot retrieve μ. The Baker-Jarvis (ε, μ) formulation is reference-plane invariant ([R6] §2.2.2; [R7] §7.5.2) but not robust at nλ_g/2 ([R7] §7.3.1; [R11]). "Robust" is justified only for: reference-plane invariance; ε-only retrieval; or multi-frequency causal regression ([R6] Ch. 3). The sentence must name which equations were solved, how (explicit or Newton), how the branch was chosen, and how the λ/2 region was treated. | "Complex ε_r and μ_r were retrieved from the four measured S-parameters with the reference-plane-invariant formulation of Baker-Jarvis et al. [NIST TN 1355-R, eqs. (2.51)–(2.57)], an extension of the Nicolson–Ross–Weir method [Nicolson & Ross 1970; Weir 1974]. The phase branch was selected by [method] (branch index reported). Near frequencies where the sample length is a multiple of half the guided wavelength, the ε/μ separation is ill-conditioned for low-loss samples. Results there are flagged [or: replaced by a two-length / causal-model solution]. For non-magnetic reference samples, ε_r was also obtained with the NIST μ_r = 1 iterative algorithm [Baker-Jarvis et al. 1990], which has no half-wavelength instability." |

## Supporting facts (for reviewers)

* "NIST Precision" in Keysight software returns ε_r only and cites Baker-Jarvis et al. 1990
  ([R34], [R35]). We did **not** find the names "NIST Precision (iterative)" or "New non-iterative"
  in the Keysight application note 5989-2589EN (2006 and 2020 versions, [R37]). If a manuscript
  uses those names, it should cite the software help it took them from.
* The Boughriet et al. (1997) method [R10] is a closed-form, μ_r = 1 permittivity formula. As
  restated by NIST [R7] eq. (99), it is ε_r = λ0²[1/λc² − (ln(1/T)/(2πL))²], with T from the NRW
  steps. It is stable at λ/2 for low-loss non-magnetic samples. It does not provide μ_r.
* The only NIST approaches described as stable over all frequencies for magnetic materials use
  more information than one sample at one position. These are two sample lengths (unstable only at
  simultaneous resonances), two-sample short-circuit line, and multi-frequency causal-model
  regression (local minima possible) ([R6] §2.2.3, Ch. 3, Ch. 4, Tables 5.1–5.2).
